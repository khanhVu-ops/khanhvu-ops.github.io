## Khi đăng

1. Một bài một ý, tối đa vài câu. Link App Store hoặc website đặt ở cuối, không đặt ở mọi bài.
2. Chỉ nêu tính năng có trong bản đang phát hành; ghi rõ khi là tính năng Pro.
3. Trả lời comment trong ngày đầu.
4. Ghi URL vào [POSTS.md](POSTS.md). Chưa có số liệu thì để trống.
